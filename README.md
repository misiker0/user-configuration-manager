# User Configuration Manager

A modular Python script designed to handle user configuration settings (such as theme, language, and notifications) using structured dictionary operations, tuple unpacking, and input normalization.

Created as part of the freeCodeCamp Python Certification curriculum.

---

### 🔑 Features

- **Setting Management:** Add, update, delete, and view system settings dynamically.
- **Data Normalization:** Converts key and value inputs to lowercase to ensure key consistency.
- **State Validation:** Checks for existing keys before updating or adding settings to prevent unintended overwrites.

---

### 🛠️ Tech Stack & Concepts Applied

- Language: Python 3
- Data Structures: Dictionaries, Tuples
- Core Concepts: Tuple Unpacking, String Formatting, Defensive Programming logic
